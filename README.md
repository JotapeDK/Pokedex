## Sobre o Projeto

A **Pokédex** é um projeto desenvolvido para praticar consumo de APIs, manipulação de dados e construção de interfaces interativas. O objetivo é permitir que o utilizador pesquise e veja detalhes de qualquer Pokémon de forma rápida e intuitiva.

---

## Tecnologias Utilizadas

- **Linguagens:** Python / JavaScript, HTML5, CSS3
- **API:** [PokéAPI](https://pokeapi.co/) *(API pública com dados atualizados do universo Pokémon)*
- **Controle de Versão:** Git & GitHub

---

##  Funcionalidades

- 🔍 **Pesquisa por Nome/ID:** Encontre Pokémons digitando o nome ou número de registo.
- 🎨 **Visualização de Tipos:** Identificação visual dos elementos (Fogo, Água, Planta, Elétrico, etc.).
- 📊 **Status & Habilidades:** Exibição dos pontos de vida, ataque, defesa e habilidades do Pokémon.
- 📱 **Interface Responsiva:** Funciona perfeitamente em computadores e telemóveis.
